# dotCalc

> A minimalist, Nothing-inspired calculator with a clean dot-matrix aesthetic.

**dotCalc** is a lightweight calculator app designed around simplicity and a distinctive dot-matrix visual style. Alongside everyday calculations, it includes **unit conversions** and **number-base conversions** for more practical and technical use.

## ✦ Features

* 🧮 **Standard Calculator**

  * Basic arithmetic operations
  * Clean and responsive interface

* 📐 **Unit Conversions**

  * Length
  * Mass
  * Temperature
  * Area
  * Volume
  * And more

* 🔢 **Base Conversions**

  * Binary
  * Decimal
  * Octal
  * Hexadecimal

* ⠿ **Minimal UI**

  * Nothing-inspired design
  * Dot-matrix visual elements
  * Monochrome aesthetic
  * Subtle animations

* ⚡ **Lightweight**

  * Fast and responsive
  * Designed for everyday use
